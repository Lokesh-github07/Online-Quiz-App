# 🎯 Quiz Application – Internship Task 9

A simple **Java console application** for conducting quizzes.  
It allows defining questions, presenting them to the user, and calculating scores at the end.

## ▶️ Run Instructions
1. Clone the repo: `git clone https://github.com/Lokesh-github07/Quiz-App.git`
2. Compile: `javac src/*.java`
3. Execute: `java QuizApp`

## 📂 Structure
- `Question.java` → model class representing a quiz question with options and correct answer  
- `QuizApp.java` → main driver class that runs the quiz and calculates the score
